# Device Statistics Service

Сервис для сбора и анализа показаний устройств (датчиков x, y, z).

## Старт

1. Установите Docker Desktop
2. Склонируйте репозиторий
3. Запустите: `docker-compose up --build`
4. Откройте: http://localhost:8000/docs

## API Эндпоинты

| Метод | URL                          | Описание                                   |
| ----- | ---------------------------- | ------------------------------------------ |
| POST  | /devices/{id}/stats          | Добавить показание                         |
| GET   | /devices/{id}/analysis       | Синхронный анализ                          |
| POST  | /devices/{id}/analysis/async | Асинхронный анализ                         |
| GET   | /tasks/{id}                  | Результат асинхронного анализа             |
| POST  | /users                       | Создать пользователя                       |
| GET   | /users/{id}/analysis         | Аналитика по всем устройствам пользователя |

## Технологии

- FastAPI - веб-фреймворк
- PostgreSQL - база данных
- SQLAlchemy - ORM
- Celery + Redis - асинхронные задачи
- Docker + docker-compose - контейнеризация
- Locust - нагрузочное тестирование

## Разработка

```bash
# Установка локально (без Docker)
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```
